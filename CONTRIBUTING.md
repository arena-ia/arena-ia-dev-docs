# Contributing to arena-ia-dev-docs

Thanks for your interest in improving this documentation! This repository is public, so before opening an Issue or Pull Request, please keep the following in mind.

## Reporting an Issue

- Check if the issue is about documentation content (wrong/outdated info) or about a technical example (code that doesn't work)
- Describe what you expected vs. what actually happened
- Never include real credentials, tokens, or internal URLs in issue descriptions or screenshots

## Submitting a Pull Request

- Keep PT and EN docs equivalent — if you update one, update the other
- Test any code examples before submitting — don't paste untested snippets
- Use placeholders for any credential-like value (e.g. `YOUR_TOKEN_HERE`, `seu_token_aqui`) — never real tokens, keys, or internal URLs
- Small, focused PRs are easier to review than large ones touching many files at once

## Code of Conduct

Be respectful and constructive. This repository is used by developers from partner companies — keep discussions professional and focused on the technical content.
