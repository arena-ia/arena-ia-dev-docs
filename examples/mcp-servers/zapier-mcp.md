# Exemplo: Zapier MCP

**Tipo:** Servidor MCP | **Auth:** Bearer Token | **Plataforma:** Zapier

O Zapier oferece suporte nativo ao protocolo MCP, permitindo conectar centenas de aplicativos à Arena IA sem escrever código.

---

## Como configurar

**1. Obtenha a URL MCP do Zapier**
- Acesse [zapier.com/mcp](https://zapier.com/mcp)
- Crie ou selecione um agente Zapier
- Copie a **MCP Server URL** gerada

**2. Obtenha o token de autenticação**
- Na mesma tela, copie o **Bearer Token** fornecido pelo Zapier

**3. Registre na Arena IA**
- Administração → Servidores MCP → Novo Servidor
- **URL:** cole a URL MCP do Zapier
- **Autenticação:** Bearer Token
- **Token:** cole o token do Zapier
- Clique em **Testar Conexão**
- As ações configuradas no seu agente Zapier aparecerão automaticamente

## Casos de uso comuns via Zapier MCP

| Ferramenta Zapier | O que o assistente pode fazer |

| Google Sheets | Ler e escrever dados em planilhas |
| Gmail | Enviar e-mails |
| Slack | Enviar mensagens em canais |
| HubSpot | Consultar e criar contatos |
| Jira | Abrir e consultar chamados |
| Notion | Criar e buscar páginas |
