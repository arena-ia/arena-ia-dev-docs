# Guia de Changelog

Este arquivo documenta como acompanhar as atualizações da plataforma Arena IA que impactam integrações.

---

## 📌 Como ler o CHANGELOG

Seguimos o padrão [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/) com versionamento semântico:

| Tipo | Significado |
|---|---|
| `Added` | Nova funcionalidade ou endpoint |
| `Changed` | Alteração em comportamento existente |
| `Deprecated` | Funcionalidade que será removida futuramente |
| `Removed` | Funcionalidade removida |
| `Fixed` | Correção de bug |
| `Security` | Correção de vulnerabilidade |

---

## 🔔 Como ser notificado

- ⭐ Dê **Star** e ative o **Watch → Releases only** neste repositório para receber notificações de novas versões
