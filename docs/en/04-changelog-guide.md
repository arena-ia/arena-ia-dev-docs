# Changelog Guide

This file documents how to track Arena IA platform updates that impact integrations.

---

## 📌 How to read the CHANGELOG

We follow the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) standard with semantic versioning:

| Type | Meaning |
|---|---|
| `Added` | New feature or endpoint |
| `Changed` | Change in existing behavior |
| `Deprecated` | Feature to be removed in the future |
| `Removed` | Removed feature |
| `Fixed` | Bug fix |
| `Security` | Security vulnerability fix |

---

## 🔔 How to get notified

- ⭐ **Star** and enable **Watch → Releases only** on this repository to receive new version notifications
