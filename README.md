## ⚡ Quick Start

**Option 1 — MCP Server**
Point your MCP-compatible server URL to Arena IA admin panel and let the platform auto-discover your tools.

**Option 2 — Custom Action**
Define a JSON action block directly inside your custom model and connect to any REST API.
